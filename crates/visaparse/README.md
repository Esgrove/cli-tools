# cli-tools-visaparse

Parse Finvoice XML credit card statements and collect the data.

Provides the `visaparse` binary.
See the [`visaparse` section](../../README.md#visaparse) of the main README for usage.

```shell
cargo run --bin visaparse -- -h
cargo test -p cli-tools-visaparse
cargo install --locked --path crates/visaparse
```
